First-time setup

      

        
Linux
Your default terminal

          
Download the launcher, then run:

          bash setup-agentdeck-terminal.sh
          Download Linux setup
        

        
Windows
Your default terminal

          
Download the launcher, then run in PowerShell:

          powershell -ExecutionPolicy Bypass -File .\setup-agentdeck.ps1
          Download Windows setup
        

      

      
Both use your agentdeck SSH alias. Your terminal theme and existing sessions stay intact.
